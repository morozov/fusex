Fuse for Windows
================

This is a binary distribution of Fuse (the Free Unix Spectrum Emulator) for
Windows. For an introduction to Fuse, see README.txt. For more detailed
documentation, read fuse.html.

Requirements
------------

A 64-bit Windows system is required for this x64 build.

Libraries
---------

This package is built with GNU MinGW-w64 on Linux. It includes libraries for
libspectrum, mbedTLS, zlib, bzip2, PNG, XML, WinSparkle, and the MinGW runtime.
